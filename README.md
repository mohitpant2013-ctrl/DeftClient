# DeftClient Launcher 🚀

A lightweight, custom Minecraft launcher built specifically for low-end PCs (optimized for old processors like Intel Core i3-380M and limited RAM setups like 6GB RAM). 

This launcher uses Java 8 and the system's bundled Java runtime to run Minecraft smoothly without eating up system resources in the background.

## Features
* **Ultra-Lightweight UI:** Built using Java Swing, consuming almost zero background RAM.
* **Low-End Optimized:** Pre-configured with `-Xmx2G` memory limits to prevent lagging on older hardware.
* **Bundled Java Support:** Uses the standard Minecraft game directory structure and bundled runtime.

## Requirements
* Java 8 installed or a valid Minecraft installation directory (`.minecraft`) on Windows.
* Maven (if building from source).
